# 选题与玩法调研（做游戏之前先做这页，半天，别超过一天）

原则：**先验证有人玩，再写玩法代码**。调研不是写论文，是填下面这张表、筛掉 2 个、留 1 个。

## 候选池（从这里面选，不要现想）

首批只考虑三类——都是单 HTML 能做、AI 生成稳、手机能玩的：

| 类型 | 例子 | 为什么适合首批 | 风险 |
|---|---|---|---|
| 合成/消除 | 2048、合成大西瓜换生肖 | 规则一眼懂，换皮成本最低 | 同类太多，美术/题材必须有差异 |
| 跳跃/跑酷 | 跳一跳、Flappy 变体 | 一局 1 分钟，适合短视频传播 | 手感难调，容易“太难/太简单” |
| 找不同/解谜 | 找不同、连连看、记忆翻牌 | 不拼手速，适合生肖 IP + 新年题材 | 单局偏长，分享率要看设计 |

不做：3D、联机对战、养成/抽卡、要账号/存档的——模板和免费部署都撑不住。

## 每个候选填一行（复制下表，3 个候选各填一份）

| 项 | 怎么填 |
|---|---|
| 玩法一句话 | “玩家做 X，得 Y 分，Z 条件结束”，一句话说不清就换一个 |
| 对标游戏 | 1 个已上线的同类（itch/CrazyGames/Poki 上能找到的），写链接 |
| 对标数据 | 对标在平台上的游玩量/评分（平台公开页能看到的就写，看不到写“未公开”） |
| 差异点 | 和对标比，我们只改 1 个点：题材（生肖/新年）/规则（1 个新机制）/节奏（二选一），不要三个全改 |
| 一局时长 | 目标 1–3 分钟 |
| 换皮成本 | 下一个换皮要改几处：只改 config + 贴图 = 低；要改 main.js 规则 = 高 |
| 传播点 | 录 15 秒短视频时，哪个画面能让人停下来（得分爆炸/差一点赢/搞笑失败） |
| 结论 | 做 / 备选 / 放弃，只选一个词 |

## 筛选标准（3 个都满足才做）

1. **一句话能说清**：给没玩过的人讲一遍，他能复述规则
2. **有对标、且对标有人玩**：没对标 = 没人验证过需求；对标没人玩 = 需求本身小
3. **模板能装下**：玩法能塞进 `TODO-GAME-1/2` 两处改完，不用改状态机/循环/统计

## 时间盒

- 调研半天封顶：上午填表、下午定 1 个。定不下来就选“生肖合成”先做——它是三类里换皮成本最低的，错了换一个也最便宜
- 调研结果存在哪：定下来的游戏在 `games/<slug>/README.md` 里写“玩法一句话 + 对标 + 差异点”；没选上的候选留在这篇文档末尾备选，不删
- 每做完一款复盘一次：把真实数据（开始率/局均时长/分享率）填回这张表，下次选题直接看表，不重新调研
